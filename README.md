# 🍕 Pizza Sales Analysis using SQL

## 📌 Project Overview
This project analyzes pizza sales data using SQL to extract meaningful business insights.
The goal is to understand sales trends, customer behavior, and product performance.

## 🧰 Tools Used
- SQL (MySQL)
- MySQL Workbench
- GitHub

## 📂 Dataset
The dataset includes:
- Orders information
- Order details
- Pizza types and prices

## 🔍 Key Analysis Performed
- Total revenue generated
- Cumulative revenue over time
- Top-selling pizzas by revenue
- Orders distribution by hour
- Category-wise performance
- Average pizzas ordered per day

## 📊 Sample Query Results
Screenshots of query outputs are available in the `screenshots/` folder.

## 🚀 How to Run
1. Import CSV files from `dataset/` into MySQL
2. Execute SQL queries from `queries/`
3. Review insights from query results
